## 4.2 Software Interfaces

### 4.2.1 Frontend-Backend Communication

Communication between frontend and backend shall occur via RESTful HTTP/HTTPS API with JSON payloads.

| Aspect | Specification |
|--------|---------------|
| Protocol | HTTPS (TLS 1.2+) |
| Request Format | JSON (Content-Type: application/json) |
| Response Format | JSON |
| Authentication | Bearer token in Authorization header |
| Error Handling | Standard HTTP status codes with JSON error object |

### 4.2.2 API Versioning

The API shall use URL versioning: `/api/v1/endpoint`

### 4.2.3 CORS Configuration

| Setting | Value |
|---------|-------|
| Allowed Origins | Application domain |
| Allowed Methods | GET, POST, PUT, DELETE |
| Allowed Headers | Content-Type, Authorization |
| Credentials | Enabled |

### 4.2.4 Rate Limiting

| Metric | Limit |
|--------|-------|
| Requests per minute | 100 per IP |
| Login attempts | 5 per minute per IP |

## 4.3 Database Interface

### 4.3.1 Database Type

SQLite version 3.x with file-based storage.

### 4.3.2 Connection Management

| Property | Specification |
|----------|---------------|
| Connection Pooling | Not required (single user) |
| Timeout | 30 seconds |
| Retry Attempts | 3 |

### 4.3.3 Query Interface

| Requirement | Specification |
|--------------|---------------|
| ORM | Optional (knex.js or direct SQLite) |
| Query Language | SQL |
| Transactions | Used for multi-step operations |

## 4.4 API Interface

### 4.4.1 Authentication API

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/v1/auth/register` | POST | Register new user |
| `/api/v1/auth/login` | POST | Authenticate user |
| `/api/v1/auth/logout` | POST | Terminate session |

### 4.4.2 Expense API

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/v1/expenses` | GET | List user expenses |
| `/api/v1/expenses` | POST | Create new expense |
| `/api/v1/expenses/:id` | GET | Get specific expense |
| `/api/v1/expenses/:id` | PUT | Update expense |
| `/api/v1/expenses/:id` | DELETE | Delete expense |
| `/api/v1/expenses/search?q=` | GET | Search expenses |

### 4.4.3 Category API

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/v1/categories` | GET | List all categories |

### 4.4.4 Dashboard API

| Endpoint | Method | Description |
|----------|--------|-------------|
| `/api/v1/dashboard/summary` | GET | Get expense summaries |
| `/api/v1/dashboard/stats` | GET | Get expense statistics |
