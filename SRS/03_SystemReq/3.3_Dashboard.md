## 3.4 Dashboard Requirements

### FR-DASH-001: Display Total Expenses

**Title**: Dashboard shows total sum of all user expenses

**Description**: The system shall display the total monetary sum of all expenses recorded by the authenticated user in the current viewing period.

**Priority**: Mandatory

**Acceptance Criteria**:
- Total calculated as sum of all expense amounts
- Displayed prominently on dashboard
- Updates immediately after expense addition
- Formatted as currency (e.g., $1,234.56)

---

### FR-DASH-002: Display Expense Summaries

**Title**: Dashboard shows expense summaries by time periods

**Description**: The system shall display expense totals grouped by time periods: current month, previous month, current year-to-date, and all-time.

**Priority**: Mandatory

**Acceptance Criteria**:
- Current month total displayed
- Previous month total displayed
- Year-to-date total displayed
- All-time total displayed
- Each total shows percentage change from previous period

---

### FR-DASH-003: Display Category Summary

**Title**: Dashboard shows expense breakdown by category

**Description**: The system shall display a summary of expenses grouped by category, showing the amount and percentage of total expenses for each category.

**Priority**: Mandatory

**Acceptance Criteria**:
- List of categories with expense totals
- Each category shows amount and percentage
- Sorted by amount descending
- Chart visualization (bar or pie) available

---

### FR-DASH-004: Display Basic Statistics

**Title**: Dashboard shows basic expense statistics

**Description**: The system shall display statistics including average expense amount, highest expense, lowest expense, and number of expenses for the current time period.

**Priority**: Should

**Acceptance Criteria**:
- Average expense amount calculated and displayed
- Highest single expense amount displayed with date
- Lowest single expense amount displayed with date
- Total number of expenses displayed
- Statistics update when expenses change
