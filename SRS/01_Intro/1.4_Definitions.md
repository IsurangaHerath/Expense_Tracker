# 1.4 Definitions, Acronyms, and Abbreviations

## Terms and Definitions

| Term | Definition |
|------|------------|
| Expense | A financial transaction with amount, date, category, and optional description |
| Category | Grouping of expenses (e.g., Food, Transport, Entertainment) |
| Dashboard | Main analytics view showing expense summaries and statistics |
| Session | Authenticated user context maintained via JWT token |
| User Story | A requirement expressed from the user's perspective |
