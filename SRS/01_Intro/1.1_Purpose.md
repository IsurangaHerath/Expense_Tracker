# 1.1 Purpose

The Expense Tracker application is a multi-user web-based system designed to help individuals record, manage, categorize, and analyze their personal expenses efficiently.

The primary purpose of this Software Requirements Specification (SRS) document is to:

- Define clear, testable, and measurable functional requirements for the Expense Tracker system
- Establish non-functional requirements that govern the quality attributes of the system
- Provide a foundation for development, testing, and project coordination among team members
- Serve as a reference for requirement traceability throughout the development lifecycle

This document is intended for the development team, project stakeholders, and quality assurance personnel involved in the Expense Tracker university project.

The SRS enables team members to:
- Understand their individual responsibilities based on feature assignments
- Develop implementable requirements for their assigned modules
- Create corresponding test cases from acceptance criteria
- Ensure consistent feature development across the application
