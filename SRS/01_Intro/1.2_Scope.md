# 1.2 Scope

## In Scope

The Expense Tracker system will provide:

- **User Account Management**: Registration, login, logout, and session management capabilities
- **Expense Tracking**: Add, view, edit, delete, and categorize personal expenses
- **Dashboard Analytics**: Total expense display, category summaries, and basic statistics
- **Search & Filter**: Expense search by description and filtering by category and date range
- **Responsive Web Interface**: Compatible with modern browsers on desktop and mobile devices

## Out of Scope

The following features are explicitly excluded from this initial release:

- Multi-currency support
- Budget allocation and tracking
- Expense sharing or collaborative expense management
- Mobile application (native app)
- Receipt image scanning/OCR
- Export/import of expense data
- Category icons or custom categories
- Third-party integrations (bank APIs, payment gateways)
- Email notifications or reminders

## System Boundaries

The system is a self-contained web application with:
- Client-side React frontend
- Node.js/Express backend API
- SQLite database storage
- JWT-based authentication mechanism

External interfaces limited to:
- User interactions through web browser
- Standard HTTP/HTTPS communication protocols
- GitHub for version control and collaboration
