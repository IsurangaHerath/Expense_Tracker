# 2.5 Design and Implementation Constraints

## Technical Constraints

### Database Constraints
- SQLite database file must be stored locally on the server
- Maximum database size constrained by available disk space
- No database server clustering or replication

### Performance Constraints
- Page load time must be < 2 seconds on average connection
- API response time must be < 500ms for 95% of requests
- Maximum 1000 expenses per user supported initially
- Maximum 10 concurrent users supported

### Authentication Constraints
- Password minimum length: 8 characters
- Passwords must include at least one letter and one number
- JWT token expiration: 24 hours
- Token refresh required after expiration

## Resource Constraints

| Resource | Constraint |
|----------|------------|
| Development Time | 6 weeks maximum (university project timeline) |
| Team Size | Maximum 7 members |
| Budget | No external budget available |
| Deployment | Shared hosting environment (GitHub Pages for frontend, local server for backend) |

## Documentation Constraints

- All code must include JSDoc comments
- README.md required for each feature branch
- Git commit messages must follow conventional commits format
- Pull request description must link to related requirements

## Integration Constraints

- No external API integrations
- No third-party authentication providers (Google, Facebook)
- No payment processing required
- No SMS or email services integrated

## Portability Constraints

- Application must run on any OS supporting Node.js
- No platform-specific code
- Database file must be portable
