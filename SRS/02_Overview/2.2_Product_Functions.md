# 2.2 Product Functions

## Function Decomposition

### Authentication Module (Member 1)
- User Registration (FR-AUTH-001)
- User Login (FR-AUTH-002)
- User Logout (FR-AUTH-003)
- Password Hashing (FR-AUTH-004)
- Session Management (FR-AUTH-005)
- Input Validation (FR-AUTH-006)

### Expense Management Module (Member 2 & 3)
- Add Expense (FR-EXP-001)
- View Expenses (FR-EXP-002)
- Edit Expense (FR-EXP-003)
- Delete Expense (FR-EXP-004)
- Validate Expense Data (FR-EXP-005)

### Category Module (Member 6)
- View Categories (FR-CAT-001)
- Assign Category to Expense (FR-CAT-002)

### Dashboard Module (Member 4)
- Display Total Expenses (FR-DASH-001)
- Display Expense Summaries (FR-DASH-002)
- Display Category Summary (FR-DASH-003)
- Display Basic Statistics (FR-DASH-004)

### Search & Filter Module (Member 5)
- Search Expenses (FR-SF-001)
- Filter by Category (FR-SF-002)
- Filter by Date Range (FR-SF-003)

## User Types

| User Type | Description |
|-----------|-------------|
| Registered User | Authenticated individual with private expense data |
| Guest | Unauthenticated; no access to system features |

## External Constraints

- No third-party API integrations
- No mobile application support in v1.0
- Single database instance for all users
