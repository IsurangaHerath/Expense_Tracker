# 2.1 Product Perspective

## Product Overview

Expense Tracker is a web-based multi-user expense management system designed for individual personal finance tracking. The application will be developed as a complete, standalone system with no external dependencies for core functionality.

## System Classification

- **System Type**: Web Application
- **Architecture**: Client-Server (2-tier)
- **Deployment**: Web-based SaaS model
- **User Access**: Multi-user, each with private data isolation

## Relationship to Other Systems

Expense Tracker operates independently from external systems for its core functionality. The application:

- Does not integrate with banking APIs or payment gateways
- Stores all data locally in SQLite database
- Requires only standard web browser access
- Uses GitHub exclusively for source code management

## Key Assumptions

1. Users have access to a modern web browser (Chrome, Firefox, Edge, Safari)
2. Internet connectivity is required for initial setup
3. Users maintain personal credentials and do not share accounts
4. Expense data is personal and not shared across users
5. All users have basic computer literacy for web applications
