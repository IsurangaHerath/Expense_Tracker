# 2.4 Operating Environment

## Hardware Environment

| Component | Minimum Requirement | Recommended |
|-----------|---------------------|-------------|
| CPU | 1 GHz processor | 2 GHz dual-core |
| RAM | 512 MB | 2 GB |
| Storage | 100 MB available | 500 MB available |
| Display | 1024x768 resolution | 1366x768 or higher |

## Software Environment

### Client-Side (Browser)
- **Operating Systems**: Windows 10+, macOS 10.14+, Linux (modern distributions)
- **Browsers**: Chrome 90+, Firefox 88+, Edge 90+, Safari 14+
- **JavaScript**: ES6+ support required
- **Cookies**: Must be enabled for session management

### Server-Side
- **Operating System**: Cross-platform (Windows/Linux/macOS)
- **Node.js**: Version 18.x LTS or higher
- **Express**: Version 4.x
- **Database**: SQLite 3.x
- **Runtime**: JavaScript/Node.js runtime

## Network Environment

| Requirement | Specification |
|-------------|---------------|
| Connection | HTTPS required |
| Bandwidth | Minimal (JSON data transfer) |
| Latency | < 100ms optimal for responsive UI |
