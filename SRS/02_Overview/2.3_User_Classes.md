# 2.3 User Classes and Characteristics

## User Class Description

### Primary User: Registered User

| Attribute | Description |
|-----------|-------------|
| **Name** | Individual Expense Tracker User |
| **Role** | Expense data owner and consumer |
| **Technical Skill Level** | Basic computer literacy; comfortable with web applications |
| **Goals** | Track and analyze personal expenses efficiently |
| **Environment** | Desktop/laptop computer or mobile device with web browser |
| **Frequency of Use** | Daily or weekly basis |

## User Characteristics

| Characteristic | Description | Recommended Minimum |
|----------------|--------------|---------------------|
| Age Range | 18-35 years old | University students and young professionals |
| Device Preference | Desktop primary, mobile secondary | Modern web browser |
| Technical Experience | Basic web navigation skills | Account creation experience |
| Data Entry | Comfortable with forms | Copy-paste capability |
| Privacy Concerns | Moderate | Expects data privacy |

## User Personas

### Persona 1: Student Alex
- **Role**: University student tracking personal finances
- **Devices**: Laptop for detailed entry, phone for quick viewing
- **Needs**: Simple expense recording, category-based spending analysis
- **Pain Points**: Forgetting expenses, mixing personal/business expenses

### Persona 2: Professional Sam
- **Role**: Young professional managing personal budget
- **Devices**: Desktop primarily
- **Needs**: Expense trends, category summaries, annual overview
- **Pain Points**: Unplanned spending, lack of spending visibility
