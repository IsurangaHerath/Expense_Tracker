## 5.7 Compatibility Requirements

### NFR-COMP-001: Browser Support

**Title**: System works on modern web browsers

**Description**: The system shall be compatible with the latest versions of Chrome, Firefox, Edge, and Safari on desktop and mobile platforms.

**Acceptance Criteria**:
- Chrome 90+ functions correctly
- Firefox 88+ functions correctly
- Edge 90+ functions correctly
- Safari 14+ functions correctly
- Mobile Safari and Chrome Android functional

---

### NFR-COMP-002: Operating System Support

**Title**: Backend runs on major operating systems

**Description**: The Node.js backend shall run on Windows 10+, macOS 10.14+, and Linux (Ubuntu 20.04+).

**Acceptance Criteria**:
- Backend starts without errors on supported OS
- SQLite compatibility across platforms
- Path handling OS-agnostic

---

### NFR-COMP-003: Device Compatibility

**Title**: System accessible on various device sizes

**Description**: The frontend shall be responsive and functional on devices with screen widths from 320px to 2560px.

**Acceptance Criteria**:
- Desktop (1024px+) fully functional
- Tablet (768px-1024px) functional
- Mobile (320px-768px) functional
- Font sizes readable without zoom
